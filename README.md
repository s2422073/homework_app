# 家事管理アプリケーション

ネイティブPHPおよびPostgreSQLを用いた、家庭内タスクのステータス管理・共有Webアプリケーション。
フレームワークに依存せず、Web 3層アーキテクチャにおけるデータバインディング、セッション管理、認証・認可の基本フローを自力で検証・実装。

## 🌐 稼働環境
* **検証URL:** https://gms.gdl.jp/~reosato/home.php
* **デモ用認証情報:**
  * 家族コード: `1`
  * 名前: `reo`
  * パスワード: `reosatou0110`

## 🛠️ 実装コンポーネント・検証内容
* **認証基盤 (`register.php`, `login.php`):** `password_hash()` によるパスワード暗号化、セッション管理によるアクセスコントロール。
* **データレイヤー (`db.php`, PostgreSQL):** PDOによる接続一元化。家族・ユーザー・タスクのERモデル設計、および外部キー制約（`ON DELETE CASCADE`）による参照整合性の担保。
* **トラブルシューティング:** アプリケーション側のインサート要件と、RDBMS側の既存スキーマ（制約・カラム定義）の不整合に対し、`ALTER TABLE` コマンドを用いたデータベースのスキーマ・制約変更による動的制御を実行。
