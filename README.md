# 家事管理アプリケーション (PHP / PostgreSQL)

ネイティブなPHPとPostgreSQLを用いた、家庭内タスク（家事）のステータス管理・共有Webアプリケーションです。
フレームワークに依存せず、Web標準技術とリレーショナルデータベースにおける「データバインディング」および「認証・認可」の基本フローを自力で検証・実装することを目的に開発しました。

## 🛠️ 技術スタックとアーキテクチャの検証内容

### 1. サーバーサイドロジック (PHP)
* セッション管理、およびユーザーリクエストに応じた動的なHTMLレンダリング（SSR）。
* `password_hash()` を用いた認証情報の暗号化、および安全なユーザー照合ロジックの構築。
* `PDO` を用いたPostgreSQLへの接続一元化（`db.php` によるカプセル化と共通化）。

### 2. データベース設計とデータ整合性 (PostgreSQL)
* 家族（`families`）、ユーザー（`users`）、タスク（`chores`）の3層のエンティティ関係（ER）を定義。
* `ON DELETE CASCADE` や `REFERENCES` などの外部キー制約を用いた、リレーショナルデータベースにおける参照整合性の実証。
* 開発・運用フェーズにおいて、コードのインサート要件（`username = {family_code}_{name}`）とDB側の既存スキーマ（`user_id` カラムの名称不整合や、過去検証時の `email` カラムに対する `NOT NULL` 制約）の間で発生したシステム不整合に対し、コードを無闇に変更するのではなく、`ALTER TABLE` コマンドを用いたインフラ（スキーマ・制約）側の動的制御によるトラブルシューティングを経験。

### 3. フロントエンド (HTML / CSS / JavaScript)
* ユーザー入力フォームに対するバリデーションの実装。
* 各タスクの進捗状況を視覚的に捉えやすい、UIコンポーネントの設計。

## 📂 リポジトリ内の主要コンポーネント
* `db.php`: データベース接続（PDOインスタンス）の初期化と一元管理。
* `register.php`: 家族コードの一意性チェック、パスワードのハッシュ化、および新規レコードのインサート処理。
* `login.php`: 暗号化パスワードの照合によるセッション開始処理。
* `home.php`: ログインセッションに基づく、紐付けられた家族内のタスクCRUD（生成・読み出し・更新・削除）制御。
