# 家事管理アプリケーション (PHP / PostgreSQL)
稼働URL:https://gms.gdl.jp/~reosato/home.php

ユーザー名：r  パスワード：reosatou0110  でログイン可能です。

家庭内におけるタスク（家事）の分担状況を可視化し、進捗管理やリソース配分を最適化するためのWebアプリケーションです。

## 🚀 プロダクトの核 (Why・How・Fact)

### 🔴 【Why】解決する課題
言語化・共有されづらい「名もなき家事」やタスクの偏りを可視化し、家庭内のリソース管理をスムーズにすることを目的としています。タスクのステータス管理を直感的に行える仕組みを目指しました。

### 🛠️ 【How】技術選定とリファクタリングへのアプローチ
* **Backend / Logic:** PHPによるサーバーサイドロジックの実装。
* **Database:** PostgreSQLを採用。タスク、ユーザー、進捗ログのエンティティ関係（ER）を定義し、リレーショナルデータベースの基礎に則って設計。
* **Status / AI協調:** 現在、データ整合性のさらなる向上とスキーマ構造の最適化を目指し、**内部ロジックおよびデータベース構造の全面的リファクタリング（再ビルド）中**にあります。そのためWeb上のエンドポイントは一時的にメンテナンスモードに設定しています。LLMを設計の壁打ち相手として、より堅牢なデータモデルへの刷新を進めています。

### 🏆 【Fact】客観的成果
* フロントエンド・バックエンド・データベース（PostgreSQL）を繋ぐWebアプリケーションの基本アーキテクチャの自力実装を経験。
* 現在進行形でリファクタリングという「既存コードのデバッグと再設計」の実務に近いプロセスを実践中。
